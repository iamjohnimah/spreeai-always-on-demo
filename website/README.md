# SPREEAI Always On marketing preview

This directory is a separate, static website concept. The shopping demo at the repository root remains unchanged.

Open: https://iamjohnimah.github.io/spreeai-always-on-demo/website/

- Nine marketing/resource pages with shared `style.css` and `app.js`.
- New generated editorial images in `assets/`.
- Existing approved videos and captions referenced from the demo’s `always-on-assets/` directory.
- Partner documents and an HTML email example in `downloads/`.
- Browser newsletter with embedded video in `newsletter/`.
- Configuration selections generate a local text download only; no form data is sent.
- No live SDK, authentication or customer-data integration. Concept and roadmap states are labeled.
- No production website deployment. The preview is marked noindex.

Email setup and compatibility notes are in `downloads/newsletter-readme.txt`.
